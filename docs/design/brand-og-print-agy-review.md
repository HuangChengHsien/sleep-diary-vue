以下依嚴重度列出兩份設計的問題與具體修改建議。

---

## 設計一：社群分享預覽圖（`og:image`）＋ `og` meta

### 高嚴重度

1. **LINE 窄版／1:1 裁切會腰斬圖示與文字**
   - **問題**：目前左右滿版橫排（內容佔 `x = 96 ~ 1104px`）。LINE 聊天室連結縮圖常採 1:1 置中裁切（只剩 `x = 285 ~ 915px`），屆時左側小屋圖示（`96 ~ 456px`）會被切掉左半、右側副標與標籤被切掉右端、底部網址與署名全被裁出畫面外。
   - **建議**：將核心視覺收攏進置中 **630×630**（或至少 **800×630**）安全區內：
     - **方案 A（最穩，置中上下排）**：小屋圖示置中縮至 `220×220px`（`margin-bottom: 20px`），下方依序置中排「眠手帳」（`96px`）、副標（`34px`）、署名（`26px`），寬度自然落在 `600px` 內。
     - **方案 B（維持左右排）**：圖示縮至 `260×260px`、`gap` 縮為 `36px`，整體水平置中並將左右 padding 加大至 `180 ~ 200px`，確保主要識別不落入邊緣裁切帶。

2. **小尺寸縮圖下，膠囊標籤與頁尾字完全不可讀**
   - **問題**：LINE 聊天室卡片寬度約 `220 ~ 260px`（縮放約 `0.2x`），手機版 FB／Threads 約 `0.3x`。
     - `.chips li`（`24px`）縮放後僅剩 **`4.8 ~ 7.2px`**，加上換行成兩列，在手機上會糊成色塊。
     - `.foot`（`22px`）縮放後僅剩 **`4.4 ~ 6.6px`**，古銅金（`#7B5D12`）細字更難辨識。
   - **建議**：
     - **移除 `.chips` 三個膠囊標籤**（三個賣點已在 `og:description` 完整呈現，圖片重複塞字反而降低可讀性），將副標放大至 `40 ~ 44px`（例如兩行精簡版：「免登入的兒童青少年睡眠日誌」／「不註冊・資料留本機・可印出看診」擇一或精簡為單行）。
     - **移除頁尾網址** `diary.kidnsleep.com`（LINE／FB／Threads 卡片下方本身就會顯示網域，圖內重複出現屬冗餘資訊）；「by KidnSleep」改放大至 `26 ~ 28px`（`font-weight: 600`）置於主標下方或副標旁。

### 中嚴重度

3. **資訊不準確且全站用語不一致：「資料只存在自己手機」**
   - **問題**：`og-image.html` 與 `index.html` 的 `og:description` 寫「資料只存在自己手機」，但產品是 Web PWA，家長與青少年也會在電腦、平板使用（尤其是列印門診報告時）；且 `meta description` 寫「本機裝置」、列印頁尾寫「使用者自己的裝置」，三處矛盾。
   - **建議**：統一改為「**資料只存在自己裝置**」或「**資料只留在本機裝置**」（`og:description` 可寫：「不用註冊，資料只存在自己裝置。記錄孩子的上床、入睡、起床與夜醒，整理成可列印的報告帶去門診。」）。

4. **`og`／`twitter` meta 缺漏且與註解矛盾**
   - **問題**：
     - `og-image.html` 註解寫「`index.html 的 og:image／twitter:image 指向它`」，但 `index.html` 實際上**沒有 `twitter:image`**。
     - 缺少 `og:image:type` 與 `rel="canonical"`。
   - **建議**：在 `index.html` 的 `<head>` 補上：
     ```html
     <link rel="canonical" href="https://diary.kidnsleep.com/" />
     <meta property="og:image:type" content="image/png" />
     <meta name="twitter:image" content="https://diary.kidnsleep.com/og-image.png" />
     <meta name="twitter:image:alt" content="眠手帳：免登入的兒童青少年睡眠日誌" />
     ```

5. **SVG 內部留白導致實際視覺尺寸與間距偏移**
   - **問題**：小屋 SVG `viewBox="0 0 512 512"` 的外圓半徑僅 `r="190"`（直徑佔 `74.2%`），四周各有約 `13%` 透明留白。設 `360px` 時實際圓形直徑只有 `267px`，視覺左側多出 `46px` 空白，與文字的視覺間距拉大到 `110px`，導致版面偏右。
   - **建議**：排版計算與對齊時須扣除 SVG 四周透明邊距（或調整容器負邊距），讓圖示外圓實緣對齊基準線。

### 低嚴重度

6. **品牌規範外硬編碼色碼**
   - **問題**：`.chips li` 使用 `#523d0a` 與 `#f5ecd4`，不在品牌規則與註解列出的 token 色票中。若依建議移除 `.chips` 即可一併消除；若保留，應回歸規範色票。

7. **`lang` 屬性不一致與文案保守度**
   - **問題**：`og-image.html` 為 `lang="zh-Hant-TW"`，`index.html` 為 `lang="zh-TW"`；另 `meta description` 的「記錄與**分析**睡眠作息」雖未觸及法規紅線詞，但用語略偏醫療評估。
   - **建議**：`index.html` 統一改為 `lang="zh-Hant-TW"`；`meta description` 改為「記錄與**整理**睡眠作息」（與 `og:description` 一致，降低 SaMD／醫療宣稱聯想）。

## 設計二：列印報告的品牌頁首與頁尾（`PrintBrand.vue`）

### 高嚴重度

1. **黑白雷射列印下，頁尾與副標字過小且網點發虛**
   - **問題**：
     - 頁尾 `font-size: 10px`（約 `7.5pt`）搭配淺棕灰 `var(--text-2)`；頁首 `.print-brand-by` 為 `11px`（約 `8.25pt`）搭配 `var(--text-2)`。
     - 黑白雷射印表機印淺灰細字會轉成半色調網點（halftone），`7.5pt` 的網點字在普通影印紙上極易斷筆畫、模糊，門診翻閱吃力。
   - **建議**：
     - 列印字級改用 `pt`（避免不同瀏覽器 DPI 縮放差異）。
     - 頁尾改為 `8.5pt ~ 9pt`（約 `11.5 ~ 12px`），顏色改為深墨 `#231C15`（或至少 `#333333`），上分隔線改為 `0.5pt solid #666666`。
     - `.print-brand-by` 改為 `9pt`（約 `12px`），顏色改為 `#333333` 或 `var(--text)`。

2. **列印強制「紙白底（`#FAF7F0`）」會導致整頁鋪滿灰黃網點**
   - **問題**：規格寫「列印時全站 token 強制為淺色、紙白底」。若 `@media print` 背景為 `#FAF7F0`，使用者開啟「背景圖形」列印時，整張 A4 會印出一層淡灰／淡黃底色，浪費碳粉且降低黑白對比。
   - **建議**：`@media print` 強制頁面底色為純白 `#FFFFFF`（不套用 `#FAF7F0`）。

### 中嚴重度

3. **頁首圖示實際視覺偏小且無法與標題左緣切齊**
   - **問題**：若 `icon-mono-dark.svg` 與小屋圖示同樣為 `viewBox="0 0 512 512"`、圓形直徑 `380`（含外圍透明留白），設 `28px` 時**實際印出的圖示直徑僅約 `20.8px`（約 `5.5mm`，非註解所稱的 `7.5mm`）**，且左側會有約 `3.6px` 透明留白，導致圖示無法與下方「睡眠數據分析報告」左緣切齊。
   - **建議**：確認 `icon-mono-dark.svg` 是否含外圍留白；若有，尺寸改為 `34px ~ 36px`（實印約 `7 ~ 7.5mm`）並加負左邊距（約 `-4px`），或另出無透明邊界的裁切版 `viewBox` 專供列印使用。

4. **品牌字體、中點分隔與垂直對齊問題**
   - **問題**：
     - 註解寫「`眠手帳 · by KidnSleep`」，但實際模板漏掉中點 `·`；且與 `og:site_name` 不一致。
     - `.print-brand-header` 用 `align-items: center`，會讓 `15px` 與 `11px` 文字底部不對齊、小字浮在半空。
     - 品牌規則規定粉圓體用於品牌字，但列印頁首「眠手帳」退回系統字，視覺與品牌主識別有落差。
   - **建議**：
     - 補上中點 `<span class="print-brand-sep">·</span>`（或與 `by KidnSleep` 組成完整署名）。
     - 文字群組改以 `align-items: baseline` 對齊（圖示與文字群組之間維持 `align-items: center`）。
     - 若想在不載入 webfont 的前提下維持粉圓體品牌字，可將「單色小屋＋粉圓體『眠手帳』」轉曲合併為單一輕量 SVG lockup（僅幾 KB）。

5. **多頁列印時的孤行與分頁識別風險**
   - **問題**：`.print-brand-header` 未設 `break-after: avoid`，且頁尾僅出現在末頁；日誌記錄印出超過 1 頁時，後續頁面無出處與免責識別。
   - **建議**：`.print-brand-header` 加上 `break-after: avoid;`（`page-break-after: avoid;`）確保不與標題分離；頁尾加上 `margin-top: 16pt;` 拉開與正文距離。

### 低嚴重度

6. **列印成 PDF 的無障礙標籤與離線圖片載入風險**
   - **問題**：
     - 頁首容器掛了 `aria-hidden="true"`，列印成 PDF 時會讓品牌名稱在 PDF 結構標籤中被隱藏（頁尾卻沒掛，兩者不一致）。
     - `<img src="/brand/icon-mono-dark.svg">` 若在 PWA 離線或未預快取狀態下觸發列印，可能因圖片未載完而印出空白。
   - **建議**：移除 `.print-brand-header` 的 `aria-hidden="true"`（保留 `<img>` 的 `alt=""` 即可）；將 `icon-mono-dark.svg` 改為 inline SVG 或確認已納入 PWA precache 清單。

## 法規紅線檢查總結
- 兩份設計所有可見文案、meta 與免責聲明**皆未出現**「診斷／治療／療法／根治／保證／最／唯一／睡眠專科」。
- 唯一保守建議：`index.html` 的 `meta description` 將「分析睡眠作息」改為「整理睡眠作息」（同上述設計一第 7 點）。
